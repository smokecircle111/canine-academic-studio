# 翻译规范

## 目标

准确传达原文论证、证据强度和学术语气，产出自然、严谨、可核对的简体中文。忠实优先于润色，术语一致性优先于同义替换。

## 基本规则

1. 不增译原文没有的因果关系、价值判断或事实。
2. 区分 `may`、`might`、`suggest`、`indicate` 与确定性陈述。
3. 保留物种名、拉丁学名、统计量、单位、引文和交叉引用。
4. 标题层级、段落、列表、脚注和引用顺序与原文对应。
5. 无法确定时标注 `[待核]`，不要凭直觉补全。
6. 术语服从 `terminology/terms.yaml`；未收录的新术语采用临时译法并进入待审清单。

## 术语首次出现

- 首次出现：`游戏鞠躬（Play Bow）`
- 后续出现：`游戏鞠躬`
- 若英文形式本身是分析对象，可按语境保留英文。

## 引文与参考文献

- 作者—年份引文不翻译姓名：`Miklósi (2015)`。
- 参考文献表原则上保留原文，不翻译论文标题，除非出版目标另有要求。
- 页码、图号和表号必须与源文件核对。

## 交付前检查

- 有无漏段、错序、数字或单位错误？
- 证据强度是否被改变？
- 术语是否与 YAML 一致？
- 首次出现是否保留英文？
- `[待核]` 是否汇总在译者注中？
