# 图表处理规范（V0.1）

V0.1 只建立分类与记录规则，不执行 AI 重绘或 OCR 自动化。

| 类型 | 处理方式 |
|---|---|
| Figure | 保留编号、标题、图注、正文引用和来源 |
| Photo | 不擅自裁切或修改；记录版权与拍摄说明 |
| Diagram | 翻译标签前先保存原标签—译名映射 |
| Flowchart | 保留节点、箭头方向、分支和层级 |
| Table | 保留行列关系、脚注、单位和显著性标记 |

使用占位符：`[图 2.3：待处理；原页码 47；类型：Diagram]`。

图注译文与正文使用同一术语库。任何重绘都必须保留原图编号、来源和“重绘/译制”说明。
